PRITI GALA WEBSITE

Files:
- index.html: page content and structure
- style.css: layout, light/dark themes, responsive styling and animations
- script.js: theme switch, mobile navigation and scroll reveal
- profile.jpg: hero profile photo

Preview:
Open index.html in a browser.

Publish on Netlify:
1. Keep all three files in the same folder.
2. Drag the priti-gala-website folder (or its contents) into Netlify's manual deploy area.
3. Connect a Git repository later if you want automatic deployments.

Customise before publishing:
- Confirm whether "mydbt" in the original technology list means MySQL or something else.
- Add real portfolio projects and testimonials when you have permission to share them.
- Review contact details and service descriptions.
- This is a static front-end website. It does not include a working enquiry database or Python backend.
